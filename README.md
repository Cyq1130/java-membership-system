# Java 会员积分管理系统

这是一个使用 Java 17 开发的简单会员积分管理系统。

## 项目简介

本项目是一个 Java 面向对象编程练习项目。

通过模拟会员积分管理系统，实现会员信息管理、会员等级判断、积分增加、积分兑换以及会员信息显示等功能。

## 主要功能

* 创建会员对象
* 保存会员姓名和会员积分
* 根据积分自动判断会员等级
* 增加会员积分
* 兑换会员积分
* 判断会员积分是否足够
* 显示会员信息
* 显示操作结果

## 会员等级

| 积分 | 会员等级 |
|------|--------|
| 1000及以上 | 钻石会员 |
| 500–999 | 黄金会员 |
| 100–499 | 白银会员 |
| 100以下 | 普通会员 |

## 使用流程示例

1. 创建一名名为 Tony 的会员，初始积分为 800。
2. 增加 300 积分。
3. 会员积分达到 1100，成为钻石会员。
4. 兑换 500 积分。
5. 剩余积分为 600。
6. 会员等级变为黄金会员。

## 学习目标

通过本项目练习 Java 基础语法及面向对象编程概念，包括类、对象、构造方法、方法、条件判断以及基础数据管理。
